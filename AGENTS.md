# Agents

If the task is Blender, a 3D prop, UVs, materials, or a glTF/WebXR asset, read `skills/blender-3d/SKILL.md` before answering or writing a script. Follow its links. Do not invent hotkeys. Do not paste video transcripts.

That skill is instructions. It does not launch Blender. To create a file, run Blender with a Python script (`blender --background --python script.py`) on a machine where Blender is installed, then export `.glb` using `skills/blender-3d/references/gltf-export.md`.

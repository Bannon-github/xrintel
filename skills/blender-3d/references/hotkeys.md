# Hotkeys

Defaults. Rebind in Edit → Preferences → Keymap. If a key does nothing, press F3 and type the tool name.

Confirm is left-click. Cancel is right-click. That applies to every transform below.

## Viewport

| Action | Key |
|---|---|
| Orbit | Middle-mouse drag |
| Zoom | Scroll |
| Pan | Shift + middle-mouse |
| Frame selected | Numpad period |
| Camera view | Numpad 0 |
| Walk navigation | Shift + backtick |
| Sidebar | N |
| Search operator | F3 |

## Object

| Action | Key |
|---|---|
| Add | Shift + A |
| Delete | X |
| Move / rotate / scale | G / R / S |
| Axis lock after G, R, or S | X, Y, or Z |
| Exclude an axis | Shift + X, Y, or Z |
| Duplicate | Shift + D |
| Join selected | Ctrl + J |
| Clear location / rotation / scale | Alt + G / Alt + R / Alt + S |
| Apply scale | Ctrl + A, then Scale |
| Mode toggle | Tab |

## Edit

| Action | Key |
|---|---|
| Vertex / edge / face | 1 / 2 / 3 on the number row, not the numpad |
| Select all | A |
| Box / circle select | B / C |
| Loop cut and slide | Ctrl + R |
| Inset | I |
| Extrude | E |
| Bevel | Ctrl + B |
| Shade Smooth | Right-click menu, or F3 |

## File

| Action | Key |
|---|---|
| Save As | Shift + Ctrl + S |
| Bump the filename number | Numpad plus or minus in the save dialog |
| Render | F12 |
